# Cloud Native meetup with Norsk Helsenett, Sikt and Sopra Steria [In-Person]

## ABOUT THIS EVENT

We are excited to invite you to a Meetup with our friends from Norsk Helsenett, Sikt and Sopra Steria This meetup is for anyone interested in Cloud native, Kubernetes and network, devops.

Mark your calendars, spread the word, and get ready for an unforgettable Meetup. We look forward to seeing you there

📍 The event will be hosted at Sopra Steria's offices at Brattørkaia
